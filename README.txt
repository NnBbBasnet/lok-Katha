LOK-KATHA GITHUB PAGES — FLAT UPLOAD

All website files are in this one folder. To upload:
1. Extract this ZIP on your computer.
2. Open the extracted folder.
3. In GitHub, open your repository, choose Add file > Upload files.
4. Select all files inside this folder (Ctrl+A), then upload and commit to main.

Keep index.html and every image/font file together in the repository root. Do not upload the ZIP itself. The page has been updated to load images and fonts from this root-level layout.
